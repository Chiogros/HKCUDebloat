# HKCUDebloat
> Debloat Windows with a few registry entries, for work as for personal use.

> [!NOTE]
> At the time of writing, it got tested on Windows 11.

## Usage
After you've downloaded [hkcud.reg]():
- _if you're allowed to do so_ double-click on the file, a message will warn you about risks and you may choose to continue
- or, open `regedit`, then `File > Import` and pick the file.

You may need to logout then login back to see changes.
